198. House Robber (Medium)

You’re a robber planning to rob houses along a street. Each house has some amount of money, given in the array nums. You can’t rob two adjacent houses, because that triggers the alarm. Return the maximum amount you can rob.

Example 1:

Input:  nums = [1, 2, 3, 1]
Output: 4
Explanation: rob house 0 (1) and house 2 (3) → 1 + 3 = 4.

Example 2:

Input:  nums = [2, 7, 9, 3, 1]
Output: 12
Explanation: rob houses 0, 2 and 4 → 2 + 9 + 1 = 12.

Constraints:

1 <= nums.length <= 100
0 <= nums[i] <= 400
