102. Binary Tree Level Order Traversal (Medium)

Given the root of a binary tree, return the values of its nodes level by level, from left to right. Each level is a separate list.

Example 1:

        3
       / \
      9   20
         /  \
        15   7

Output: [[3], [9, 20], [15, 7]]

Example 2:

Input:  root = [1]
Output: [[1]]

Example 3:

Input:  root = []
Output: []

Constraints:

The number of nodes is in the range [0, 2000].
